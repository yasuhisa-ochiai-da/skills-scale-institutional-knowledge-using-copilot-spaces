# OctoAcme Project Management Documentation

Welcome to the central index for OctoAcme's project management process documentation. This README provides an overview of our approach, links to all process documents, and a quick-reference guide to help you find the information you need.

---

## Overview

OctoAcme follows a structured, customer-centric project management approach built on five core principles:

- **Customer-first** – Prioritize customer value and usability in every decision.
- **Iterative delivery** – Deliver small, testable increments to reduce risk and gather feedback early.
- **Clear ownership** – Every project has a named Project Manager (PM) and Product Lead accountable for outcomes.
- **Data-informed decisions** – Measure impact and iterate based on evidence rather than assumptions.
- **Psychological safety** – Encourage open feedback and learning from both successes and failures.

### Project Lifecycle

The project lifecycle consists of five key phases:

| Phase | Description |
|-------|-------------|
| **1. Initiation** | Define the problem statement, identify stakeholders, and establish a high-level timeline. |
| **2. Planning** | Finalize scope, allocate resources, set milestones, and map dependencies. |
| **3. Execution** | Build, test, review, and iterate using daily standups and pull-request workflows. |
| **4. Release** | Deploy, verify, and announce with pre-release checklists and rollback plans ready. |
| **5. Close & Retrospective** | Capture learnings, document improvements, and celebrate the team's work. |
